# doudou UP · 拼豆图纸生成器

把图片或手绘变成可打印的拼豆图纸。**单个 HTML 文件，双击就能用** —— 不用安装、不用联网、不上传任何图片。

> A single-file, offline Perler / Hama bead pattern generator. No build step, no server, no upload.

**[在线使用 →](https://guqiao5757-png.github.io/doudou-up-beads/)**

---

## 快速开始

**在线用**：打开上面的链接即可。

**离线用**：下载仓库里的 **`doudou up.html`**（约 116 KB），双击用浏览器打开。所有字体、调色板都已内嵌，断网也完整可用。

---

## 能做什么

| 功能 | 说明 |
| --- | --- |
| 画布 | 预设 24/32/40/48/60，或自定义 **4–200** 任意尺寸 |
| 调色板 | **MARD 221 色**标准色号（A1–M15），按色系分组 |
| 绘图工具 | 画笔、橡皮、吸管、油漆桶，支持撤销/重做 |
| 参考底图 | 上传图片半透明叠加，手动描图；支持「适应/拉伸」两种贴合方式 |
| 图片转拼豆 | 一键把照片转成拼豆图，可调采样方式与白色处理 |
| 图案变换 | 水平/垂直镜像、顺/逆时针 90° 旋转 |
| 视图 | 滚轮缩放、拖拽平移、一键适应窗口 |
| 导出 | **JPG**（图案 + 已使用颜色图例）、**CSV** 豆子用量清单、JSON 存档/恢复 |

### 导出的 JPG 长什么样

图案画在上方并水平居中，下方用分隔线隔出**已使用颜色图例**：每种颜色给出 **色块 + 色号 + 颗数**，顶部标注「已使用颜色 N 种 / 共 M 颗」。颜色过多时自动换行排布，打印出来照着配色即可。

## 图片转拼豆：四个参数怎么调

这是最容易踩坑的地方，按下面选基本不会出错：

| 参数 | 怎么选 |
| --- | --- |
| **采样方式** | 实拍照片用「区域平均」（平滑、抗锯齿）；像素图/线条图用「中心点」（边缘更锐利） |
| **扣白底** | 白底图必开；深色或复杂背景图要关掉，否则浅色细节会被误抠 |
| **白色抑制** | 想减少死白、让画面更有色彩时开；系数越大，白豆越少 |
| **自动抑制** | 白豆占比超过上限时自动加码，不用手动反复试系数 |

> 注意：「自动抑制」**不能替代**扣白底和白色抑制。扣白底决定"这个位置该不该放豆子"，发生在颜色匹配之前；自动抑制只是在后面帮你调白色抑制的系数。

## 本地开发

```
bead-pattern/
├── index.html        # 页面结构
├── styles.css        # 样式（字体 base64 内嵌）
├── app.js            # 全部逻辑（约 1600 行，零依赖）
├── build_single.js   # 构建脚本：把 css/js 内联成单文件
├── ps2p.woff2        # Press Start 2P 像素字体
├── docs/index.html   # 构建产物，供 GitHub Pages 托管
└── doudou up.html    # 构建产物，离线单文件版
```

改完代码后执行：

```bash
node build_single.js
```

它会同时更新三处：`doudou up.html`（离线版）、`docs/index.html`（Pages 版）、以及桌面上的副本。

直接双击 `index.html` 也能调试（它会外链 `styles.css` 和 `app.js`，改完刷新即可）。

## 关于点赞计数（可选）

页面右上角的点赞数默认走**离线降级**：存在本地浏览器里，只作展示，不是真实统计。

想接真实全局计数，仓库里附了一个零依赖的 Node 服务：

```bash
node like-server.js        # 默认 3000 端口，可用 PORT 指定
```

然后把 `app.js` 顶部的常量指向它：

```js
const LIKE_API_BASE = 'https://your-host.com';   // 留空 = 离线降级
```

接口只有两个：`GET /api/like` 读取、`POST /api/like` 自增，计数持久化在 `like-count.json`（已在 `.gitignore` 中忽略）。
